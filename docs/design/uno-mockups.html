Scoring Uno & Uno Flip

Uno scores differently from Phase 10. Only the player who goes out scores each hand, and their score is the total of the cards left in everyone else's hand. This page covers the rules the model has to encode, four modelling decisions, and three interactive mockups for entering a hand. Choices made on 14 September 2026 are marked; the agreed plan is in uno.md next to this file.

Winner collectsWhoever goes out scores the sum of every opponent's remaining cards. Everyone else scores 0 for that hand.
Points-against variantAn official alternative: each player records the cards left in their own hand. When anyone reaches 500, the lowest total wins.
Draw before countingIf the last card played was a Draw Two or Wild Draw Four (in Flip, whatever draw card is showing), the next player draws those cards before anyone counts.
PartnershipsWith 4 players, partners can sit across from each other and share one score. It's rare, but the rules allow it.
Model & module

Four modelling decisions

One module or two?

How Classic and Flip appear in the game grid
DecidedOne “Uno” tile, variant picked at New Game

One UnoGame model with a variant field. The list cell shows a “Flip” badge. No Core changes needed.

Two tiles that share one model

Easier to find, but GameSession.fetchDescriptor is static, so GameSessionList would need a predicate per module. That's a Core change.

Two separate models

Duplicates the model, views and tests for what is really just a different table of card values.

What a hand stores

Per CLAUDE.md, derived state is computed and never stored
DecidedWinner, Flip side, and points left per player

The card counter is only an input aid that produces a number. Works with every entry style in this page, and matches Phase 10.

Full card counts per player

Editing a hand later would reopen the tally, and changing the Flip side would recompute it. Costs: a bigger schema, and a player who counts in their head has nowhere to type a total.

Scoring mode

Winner-collects versus points-against
DecidedA per-game setting, winner-collects by default

The data you enter is the same in both modes. Only the attribution changes, and whether the high or low total wins.

Winner-collects only

Simplest to build. Groups that play points-against, which is common with kids, can't use it.

Card values as data

Uno has many special editions
DecidedA table keyed by variant and side

UnoVariant.cardValues(side:) returns the cards as [(kind, points)]. Adding Show ’Em No Mercy later means adding one table.

enum UnoVariant: String, Codable { case classic, flip }
enum UnoScoring: String, Codable { case winnerCollects, pointsAgainst }
enum UnoSide: String, Codable { case light, dark }

@Model final class UnoGame {
    var players: [PlayerRef] = []
    var variant: UnoVariant = .classic
    var scoring: UnoScoring = .winnerCollects
    var targetScore: Int = 500
    var startingDealerIndex: Int = 0
    var hands: [UnoHand] = []

    func cumulativeScore(for player: Int) -> Int   // computed from hands + scoring mode
    var isFinished: Bool                           // anyone ≥ targetScore
    var winnerIndex: Int?                          // max (winnerCollects) or min (pointsAgainst)
}

struct UnoHand: Codable, Identifiable {
    var id = UUID()
    var wentOutIndex: Int
    var side: UnoSide = .light                    // meaningful only for .flip
    var pointsLeft: [Int]                          // one per player; winner's is 0
    var handValue: Int { pointsLeft.reduce(0, +) }  // what the winner collects
}

Decided on 14 September 2026

What version 1 will build

  1. One Uno tile. Classic or Flip is chosen at New Game. A hand stores who went out, the Flip side, and pointsLeft for each player.
  2. Both scoring methods, chosen per game: winner collects (the default) and points against.
  3. Hand entry is A · Quick Total. Each opponent's row has a “Count” button that opens B · Card Pad and writes the total back, because it's easy to forget individual card values.
  4. The score sheet follows the scoring method: 2 · Race + hand log for winner collects, 1 · Ledger grid for points against.
  5. Editions: Classic and Flip only.

Deferred

Partnership play

Not played yet, so 2-v-2 teams wait for a later update.

Uno Attack, Uno All Wild

Each needs only a card-value table and a Card Pad layout.

Show ’Em No Mercy

Also needs knock-outs modelled: a player holding 25 or more cards is out, whoever knocked them out gets 250, and the game plays to 1,000.
